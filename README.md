# Das-verschwundene-Wochenende
Drei Jugendliche – Carmen, Maria Christina und Andreas – müssen ihr verschwundenes Wochenende retten. In sechs geheimnisvollen Räumen lösen sie Rätsel rund um Hobbys und Freizeit, entdecken Hinweise und entschlüsseln Codes. Nur wer genau liest, kombiniert und auf Deutsch denkt, findet den Weg zum Finale.
